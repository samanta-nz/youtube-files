```

└── tools/
    ├── images/season-2-hack/   thumbnails (۱۵) + slides (۹۰ × ۱۹۲۰×۱۰۸۰)
    ├── scripts/season-2-hack/  ساختار روایت فصل‌ها + کد بازتولید
    └── data/season-2-hack/     متادیتا، زیرنویس، متن خام + book-info.json
```

برای جزئیات به `روانشناسی تاریک/README.md` و `روانشناسی تاریک/INVENTORY.md` بروید.
